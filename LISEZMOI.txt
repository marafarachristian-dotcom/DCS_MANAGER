DCS MANAGER — application web installable (PWA)

CONTENU DU DOSSIER (à envoyer tel quel, tous les fichiers à la racine du dépôt GitHub)
  index.html            l'application
  manifest.webmanifest  nom, couleurs et icônes de l'application installée
  sw.js                 fonctionnement hors ligne
  icon-192.png, icon-512.png, apple-touch-icon.png   icônes

MISE EN LIGNE (GitHub Pages)
  1. Créez un dépôt public (par exemple DCS_MANAGER) avec un README.
  2. Add file > Upload files : glissez les 6 fichiers (pas le zip), puis Commit changes.
  3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
  4. Ouvrez https://VOTRE-COMPTE.github.io/DCS_MANAGER/

INSTALLATION SUR TÉLÉPHONE OU ORDINATEUR
  Android / Chrome : bouton « Installer l'application » en bas à droite, ou menu > Installer l'application.
  iPhone / Safari  : bouton Partager > Sur l'écran d'accueil.
  Ordinateur       : icône d'installation dans la barre d'adresse (Chrome, Edge).
  Ouvrez l'application une première fois avec Internet : elle fonctionne ensuite hors ligne.

METTRE À JOUR
  Remplacez index.html sur GitHub. Pour forcer la mise à jour chez tous les utilisateurs,
  changez aussi le numéro VERSION au début de sw.js (dcs-manager-v1 devient dcs-manager-v2).

IMPORTANT
  Les données restent dans le navigateur de chaque appareil : elles ne sont ni partagées ni sauvegardées en ligne.
